# Voice-Based Email System for Blinds

## Overview
The Voice-Based Email System for Blinds enables visually impaired users to manage emails through voice commands. Users can compose, send, receive, and read emails without using a keyboard or mouse.

## Features
- Voice-based login
- Compose emails using speech
- Read incoming emails aloud
- Send emails using voice commands
- User-friendly interface for visually impaired users

## Technologies Used
- PHP
- MySQL
- Android Studio
- SMTP
- IMAP
- Speech-to-Text (STT)
- Text-to-Speech (TTS)

## How It Works
1. User gives voice commands.
2. Speech is converted to text.
3. The system performs email operations.
4. Results are read back to the user through audio.
